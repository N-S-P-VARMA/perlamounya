# Perla Lalitha Mounya — Portfolio

A polished, responsive portfolio built from the supplied resume.

## Run locally
Because this is a static site, you can open `index.html` directly, or serve it with a local server:

```bash
python -m http.server 5173
```

Then visit `http://localhost:5173`.

## Deploy
Upload the folder to GitHub and import the repository into Vercel, Netlify, or GitHub Pages.

## Notes
- No framework/build step required.
- Three.js is loaded from jsDelivr for the lightweight 3D hero effect.
- All portfolio copy is based on the supplied resume.
- Contact links are configured from the resume details.
- Reduced-motion users receive a simpler animation experience.
